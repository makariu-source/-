# ЗооБокс

Сайт сервиса ЗооБокс для клиентов: регулярная доставка корма и наполнителя по умной автоподписке.

Весь сайт находится в одном файле `index.html`: HTML, CSS и JavaScript. Чтобы посмотреть сайт, откройте этот файл в браузере.

Текущая версия: 1.2, история изменений — в `CHANGELOG.md`.

Что есть на странице:
- главный экран и как это работает;
- что в коробке для собак и кошек;
- контроль над подпиской: пропуск, перенос, отмена;
- аналитика: рынок и экономика;
- подбор коробки: порода, возраст, вес, стоимость и график доставки.
