# ЗооБокс

Лендинг для защиты бизнес-кейса (Кейс-батл ВШЭ, 2026): сервис регулярной доставки корма и наполнителя по умной автоподписке.

Весь сайт находится в одном файле `index.html`: HTML, CSS и JavaScript. Чтобы посмотреть сайт, откройте этот файл в браузере.

Что есть на странице:
- главный экран и ценность сервиса;
- стратегия запуска MVP;
- ответы на неудобные вопросы (аккордеон);
- рынок, экономика клиента, плюсы и минусы;
- интерактивный калькулятор подписки.
